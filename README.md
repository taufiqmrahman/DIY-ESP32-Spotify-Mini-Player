# 🎵 DIY ESP32 Spotify Mini Player

This project is a hardware-based Spotify controller built with an ESP32. 🎛️ It uses the Spotify Web API to fetch currently playing track data and display it in real-time on a 1.3" OLED screen. 📺 It also features tactile buttons for physical playback control (⏮️ Previous, ⏯️ Play/Pause, ⏭️ Next) and a potentiometer for smooth analog volume adjustment. 🔊
